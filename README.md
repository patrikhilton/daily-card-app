# Daily Card App

Group project by Patrik, Chee and Tharanga.

## How to run it

```
git clone https://github.com/patrikhilton/daily-card-app.git
cd daily-card-app
npm install
npm run dev
```

## Team rules

1. Never push directly to `main`.
2. Before starting work: `git checkout main` and `git pull`.
3. Make a new branch for each task: `git checkout -b feature/your-task`.
4. Push your branch and open a pull request on GitHub.
5. Someone else reviews it before it gets merged.
6. Put new components in `src/components`.
